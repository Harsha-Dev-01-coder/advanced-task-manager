# Advanced Task Manager

A modern task management application built with React, TypeScript, Redux Toolkit, React Router, and Tailwind CSS.

This project is being built as a full-featured frontend application with scalable architecture and production-oriented practices.

---

## 🚀 Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Redux Toolkit
- React Redux
- React Router
- ESLint
- Git & GitHub
